Windows 本地运行：双击“启动游戏.cmd”。无需安装 Node 或开发工具，无需联网。
游戏在默认浏览器打开，启动日志窗口保持打开。结束时点击网页上方的“结束游戏并关闭服务”，关闭启动日志窗口，或双击“关闭本地服务.cmd”。只关闭浏览器页面不会结束服务。
再次双击启动会复用本份游戏的服务。关闭后再次启动，同一路径通常使用同一个本机端口；若端口已被别的程序占用，会使用相邻端口。浏览器存档按本地地址隔离，端口或目录改变时旧存档不会自动迁移。
移动、改名或分享时请复制整个 web 文件夹，包括 .webgal-local，不能只复制入口文件。入口仅支持 Windows PowerShell 5.1 或更新的 Windows PowerShell 与本地磁盘目录；组织策略禁止脚本执行时请联系设备管理员。
正式网页发布：将同一文件夹完整上传到 HTTP(S) 网站，使用 index.html。不需要上传本地启动入口。双击 index.html 的 file:/// 打开方式不能可靠运行当前模块与资源请求；不要用它判断游戏内容损坏。
本地服务只绑定 127.0.0.1，不能给另一台电脑通过此地址访问。不会启动 Terre、修改游戏、安装软件或下载组件。再次导出时可先结束游戏，避免演出中资源被替换。
