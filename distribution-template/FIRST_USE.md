# 第一次使用 WebGAL 附件

这是为 WebGAL 创作者准备的本地 Live2D 动态附件工具。你可以把透明 PNG 放在人物的指定部位，让它随人物动作移动，再保存为可复制、可跨游戏使用的完整附件。

准备：受支持的 Windows x64 WebGAL MyGO 3.2.0 / Terre 宿主、自己有权使用的完整 Live2D 模型，以及对应的锚点配置。本工具不附送人物模型，也不会自动适配任意模型。安装前关闭 Terre、制作器网页和制作器日志窗口，保留游戏与资料备份。

1. 使用发行包的安装入口选择受支持宿主；安装完成后用 `03_验证安装.cmd` 检查。已经验证成功，无需重复安装。
2. 用 `02_打开附件制作器.cmd` 打开工作台。它附带的命令窗口用于显示日志，使用期间保持打开。
3. 选择角色，再选择服装/立绘外观并显示人物。如果导入自己的模型，选择完整资源目录，包含模型、纹理、动作等依赖；只选一个模型文件通常不够。确认选中的外观有可用锚点。
4. 载入一个已有附件或自己的 PNG。内置快捷附件与普通附件一样可以编辑。选择跟随部位，调整位置、大小、角度。单图可以直接切换人物前面/后面；后层被人物遮挡是正常效果。
5. 点“保存附件”，把图片和人物参数保存到本地资料库。这里不需要选择游戏。成功结果会告诉你附件名称与完整文件夹位置。
6. 需要在游戏中使用时，再选择目标游戏，点“添加 / 更新到这个游戏”。如果游戏缺少人物模型，按提示补齐或复制人物后再添加。
7. 到 Terre 打开结果中给出的“附件测试-名称-短标识.txt”。先确认人物和附件出现，再逐步检查动作与位置；满意后按需要在自己的剧情里调用。

同一个附件可以保存多个人物/外观的不同参数。先载入目标人物，再载入同一个附件：有适配就恢复，没有时从明确的默认参数开始调整。保存仍是同一个附件，其他人物的配置保留；图片共用一份。语义部位相同不保证不同人物的大小、偏移恰好一样。

“另存为新附件”会生成新的附件身份；“导出完整附件文件夹”保留当前身份，复制出可携带的文件夹；“添加到游戏”则更新指定游戏里的副本。修改本地资料库不会自动同步所有游戏。

双层附件切成单层时，另一张图暂留本次工作台，切回双层可恢复；保存或导出只包含所选层。需要保留两层成品时，先切回双层再保存。

结束后可用 `05_停止附件服务.cmd` 关闭后台。遇到错误先保留完整提示，不要反复安装、删除锁文件或覆盖原附件。反馈时使用随附的问题反馈模板。
