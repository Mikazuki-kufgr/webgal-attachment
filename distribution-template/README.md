# MyGO 3.2.1 附件插件技术候选

修订：MYGO321-CANDIDATE.1；版本：0.5.0-beta.1。

本包是可安装技术候选，不是已发布公测，也不代表 GUI、GPU、真实 Live2D 动作或用户视觉验收已经通过。

支持边界：仅本项目归档的社区整合包 WebGAL_Terre_MyGO_v3.2.1.zip（SHA-256 前缀 028F20B8）及 manifest 指定的完整 adapter。不是任意名称相同的 3.2.1。不能直接覆盖已安装 3.2.0 插件的宿主；跨宿主迁移需独立流程。

安装会替换 Terre 后端、编辑器以及 assets/templates/Derivative_Engine/MyGO_v3.2.1 下的插件构建目标；保留官方 WebGAL_Template、用户游戏、素材和外来文件。发行参考文件差异不阻断；只读依赖和受管目标按各自合同核验。卸载使用本次安装记录的实际备份恢复。

普通入口为 01_安装或升级.cmd；须选择该整合包 release 目录及明确的作者模板游戏、资料库目录。不要选游戏目录充当宿主。运行前关闭占用所选宿主的 Terre/Creator；不自动关闭用户进程。

现有游戏的引擎不会被静默升级。应使用已验证的插件 MyGO 引擎创建隔离测试游戏；附件成品可复制，但 Runtime 支持须独立验证。默认官方引擎不具备附件脚本支持。

SDK 和模型二进制不随插件分发；仅引用用户宿主/模板项目已有内容。法律/公开发行依赖复审未关闭。本包包含可编辑样例与 Profile 技术数据，不代表捆绑所有模型。

构建源码来自官方 tag MyGO 3.2.1（engine ed73e55a87546cf0bc495a95061ccce2dafdf7cb，Terre cf015023e64188e4415ddf18aa536b8606c9c875）叠加 Hotfix44 附件改动。本机独立构建和校验入口见同任务源码目录的 build.mjs、assemble.mjs 及 evidence。node 24.19.0 用于工具，EXE 使用 @yao-pkg/pkg 6.4.1 / node22-win-x64。

旧版行为限制仍可能存在；不要把技术候选用于唯一副本或直接公开发布。视觉问题、兼容性问题应附版本、操作和日志反馈。
