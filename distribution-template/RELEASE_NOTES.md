# 0.5.0-beta.1 / MPB1-5L-HOTFIX.44

本版完成 Hotfix44 公测前最小收尾：统一当前版本、宿主基线、Known Issues、Release Notes 与发行状态。新增独立代码采用 MPL-2.0；五套默认附件图片采用 CC0-1.0。代码与图片具体边界见 NOTICE.md。

Hotfix44 已完成并接受 S43-01 / S43-02 / S43-03。K44-01（同一编辑页连续 `a.txt → b.txt → a.txt` 后当前保存会话可能被 P2 代际冲突拒绝）保留为不阻断 Beta 的 Known Issue，不在本轮追加代码修复。TECHNICAL 与对应 SOURCE 已完成 ChatGPT 静态/封包核对；最终真人安装/GUI smoke 仍是下一步，未伪造 `publicBetaCandidateReady`、`realHostInstalled` 或 `guiValidated`。

本版沿用 Hotfix36 已接受的功能行为。制作器重新编译用于显示本版修订号；Engine、Terre 编辑器、后端与独立预览复用完全相同的已验证输出。没有新增锚点工具、自动换装、快进处理或新的模型适配，也不覆盖用户调好的附件和剧情。

## 已完成的代表流程

- 本地完整模型导入、复用已有 Profile、制作与动作跟随检查。
- 同一附件共用图片，保存多人物/外观的独立参数并恢复。
- 资料库保存、另存为新身份、完整文件夹导出与冲突保护。
- 添加到游戏、中文独立验证剧情、Terre 与独立 Web 成品运行。
- 前后层切换、保存成功与按钮恢复、服务停止、安装验证。
- Terre 保存失败时保留草稿并明确提示，解除阻碍后成功重试；Web 导出失败与重试。

这些是技术核验与代表性用户验收的范围，不能等同于全部 97 套外观、所有浏览器和所有宿主版本均已测试。完整限制见 KNOWN_LIMITATIONS.md。

升级：关闭相关应用，运行新包的01，再运行03验证。保存资料库与添加到游戏仍是独立操作；升级不会自动把资料库的新参数同步到所有游戏。请保留自己的完整附件、模型与游戏备份。

# Hotfix38 — F04 自由附件独立恢复

修复人物全部退场后，自由附件读档无法恢复的问题。恢复直接使用已保存的附件配置和 Profile，不再借用舞台人物；位置、缩放、旋转、透明度、显隐与重新绑定合同保持。资源缺失或 Profile 歧义明确诊断。该历史修订的自动验证和未完成 GUI 门禁按当时记录保留。

# Hotfix39 — F04 分离前显隐同步修复

修复人物效果在提交后更新时，附件淡入可见终态未同步、下一句重新隐藏草帽的问题；继承 Hotfix38 的无人物自由附件恢复。历史自动验证、视觉边界和未发布状态按当时记录保留。

# Hotfix40 — F05 当前磁盘保存确认

未改稿的再次保存或执行先只读核对磁盘；外部改动提示冲突、保留草稿和磁盘并阻止执行。该历史修订的保存并发边界和验证范围按当时记录保留。

# Hotfix41 — Terre 路径、本机访问与安全保存

历史修订加入路径边界、本机 Host/Origin 有界防护和安全临时文件替换；不将有界防护扩大解释为完整会话鉴权。既有 F04/F05 接受范围保留。

# Hotfix42 — 修复打包 EXE 启动目录

历史修订使打包 EXE 默认从自身目录定位资源，显式 `--cwd` 仍优先；启动失败在初始化用户数据前明确停止。Engine/Creator/Preview 沿用当时已验证产物。

# Hotfix43 — 网页资源改名同步已打开编辑器

历史修订使 Terre 资源侧栏改名后同步已打开标签、当前标签和场景保存身份；未保存/保存中先等待，失败保留原状态。该历史事件及其用户接受记录保留，不因本次文档收尾重写。

# Hotfix44 — 最终公测技术包

Hotfix44 同时更新 Origine2 编辑器前端和 Terre 后端：重命名失败不会提交前端身份迁移；规范化重名目标由后端拒绝；单文件改名后重建旧路径时隔离旧保存会话与修订历史。最终技术包重新生成后端 EXE，并拒绝此前误带入的 Hotfix43 EXE；隔离 API 冒烟确认后端回执和磁盘改名成功。
