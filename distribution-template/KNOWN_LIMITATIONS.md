# 支持范围与已知限制

本文件按 Hotfix44 当前证据整理，供 `0.5.0-beta.1` 公测候选包使用；元数据已对齐，最终真人安装/GUI smoke 尚未完成。

- 目标是已核验的 Windows x64 MyGO 3.2.0 / Terre 宿主，不保证其他版本或平台可直接安装。
- 已有锚点配置的代表模型已走通导入、制作、独立保存、添加到游戏及 Terre 剧情流程。11 人 97 套语义 Profile 是配置元数据，不是 97 套附送模型，也不是全部外观已经人工验收。
- 未知模型缺少适合的 Profile 时，不能直接制作可跟随的附件。离线锚点制作工具与任意第三方模型自动适配不属于本次提供的能力。
- 每个附件可以共享图片、分别保存各人物/外观的锚点与摆放参数。尚未针对目标外观调整的默认参数需要检查，不能视作自动适配完成。
- 拼好模仍由 WebGAL 的多个独立立绘实例组成。附件绑定其中一个实例；用户负责选择包含目标部位的实际模型和有效锚点。组合模型场景未取得专项视觉验收，不承诺跨实例联合跟随。
- 普通 Web 独立导出已有代表性验证；Windows EXE、Android 导出以及其他 runtime、完整 mask/clip 不在已验收范围。
- 部分环境的新标签页/独立 Web 曾出现人物与附件共同卡顿，原因未定。不能将其归咎于附件，亦不保证所有环境流畅；性能专项按项目裁决延期。
- 已验证布局支持中文与空格。已安装目录整体搬家、复制、上级改名、跨盘和特殊文件系统尚无完整验证，不应直接假定复制后即可工作。
- “导出完整附件文件夹”受浏览器目录接口限制，可能只能显示所选目录名和子目录，不能提供本机绝对路径。保存到本地资料库或添加到游戏的结果可以显示完整路径。

- K44-01（P2，不阻断）：同一编辑页面内连续执行 `a.txt → b.txt → a.txt` 后，当前保存会话可能被误报为代际冲突而拒绝保存；先保存/另存好正文，遇到冲突先复制未保存草稿，再刷新整个编辑器页面并重开核对。避免多编辑页或外部程序同时改名/写入同一文件。本限制不代表已发生覆盖或数据丢失。

本候选的完成项与待办见 RELEASE_READINESS.md；技术检查不代替普通界面和用户视觉接受。

## 公测后体验优化

- 角色/服装选择后仍需显式载入；自动载入与切换前未保存提醒延期。
- reattach/remove快进仍可能等待过渡结束，按用户反馈记录，不承诺已修复。
- 持续保存失败提示区域较醒目，后续改为可收起的简短状态；当前仍需注意未保存风险。
- 结束制作推荐05停止服务；02日志窗口直接关闭体验仍待完善。
