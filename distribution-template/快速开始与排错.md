# WebGAL Attachment 快速开始与排错

本文面向第一次使用插件的用户。正常使用不需要编辑 JSON、理解哈希或使用命令行；详细错误码仍会保留在窗口中，便于有经验的用户检修。

## 安装前

- 当前候选版只适配明确标注的 MyGO 3.2.0 / WebGAL Terre 4.6.2 Windows x64 版本。不要把它装入其他 Terre 版本。
- 先关闭正在运行的附件制作器。安装器发现仍在运行的制作器时会停止并提示，不会强行覆盖。
- 插件不携带Live2D SDK或人物模型。用户可以通过明确的导入和复制按钮准备自己的模型；原模型与原图片不移动、不删除。
- 01安装入口已提供文件夹和游戏选择；普通用户无需手写 `install-request.json`。

## 六个入口分别做什么

1. `01_安装或升级.cmd`：首次安装或覆盖到更新的插件版本。重复运行同一完整版本不会重复写入。
2. `02_打开附件制作器.cmd`：启动本地制作器。这个 CMD 是实时日志窗口，使用期间不要关。
3. `03_验证安装.cmd`：只检查安装状态，不修改游戏内容。普通窗口显示中文结果、版本、目标和详细诊断文件路径；不直接展开JSON。
4. `04_修复安装.cmd`：只修复插件自己受管且可证明需要修复的文件，不覆盖用户附件、剧情或模型。
5. `05_停止附件服务.cmd`：只停止由本插件启动并能验证归属的制作器服务。
6. `06_卸载插件.cmd`：移除插件受管文件并恢复安装前保存的宿主文件；用户附件和游戏内容不属于卸载对象。

## 第一次制作附件

1. 运行 `02_打开附件制作器.cmd`，保留日志窗口。
2. 在网页首步选择一个本地人物与外观，点击“在工作台中显示”。
3. 选择草帽、兽耳、光环、花朵、玫瑰样例，或点击“制作自己的附件”并选择透明 PNG。
4. 选择语义锚点，拖动并调整位置；高级效果默认关闭，需要时再显式启用。
5. 选择目标游戏并保存。原 PNG 留在原位置，保存只会把副本放进附件自己的完整文件夹。
6. 页面显示成功后，可打开刚保存的独立验证剧情检查；制作器预览通过不等于 Terre 或正式游戏运行时已经通过。

## 直接编辑和迁移附件

附件的完整目录位于目标游戏的 `game/attachments-v2/portable/`。每个成品至少包含 `attachment.json`、`images/`、`manifest.json` 和 `使用说明.txt`，可以整体复制到另一个游戏。不要只复制一张 PNG。

你可以不用制作器，直接修改 `attachment.json`、替换附件图片或移动完整附件目录。重新进入制作器时若检测到外部修改，会列出差异并让你选择接受当前磁盘内容或取消；不会把结构仍有效的用户修改静默覆盖掉。

## 常见问题

### 页面提示目标游戏缺少人物模型

制作器工作台里的人物和目标游戏里的模型是两份不同内容。载入或切换附件时，制作器会提前检查目标游戏：如果模型还没准备好，只显示“仍可继续编辑、保存前需要补齐”的黄色提醒，不代表附件载入失败。

真正点击保存时仍会阻断，并显示 `CREATOR_TARGET_MODEL_MISSING`、缺失文件的安全相对路径和处理建议。对于当前导入人物，先选择目标游戏，再点击“将当前导入人物复制到第4步所选游戏”，等待成功后保存。完整顺序见[人物导入指引](LOCAL_MODEL_IMPORT.md)；不要靠猜路径或手工覆盖同名模型解决问题。

### 打开制作器后暂时不能选择人物

首次启动会读取项目与 Profile。按钮在准备完成前会暂时禁用；如果最终失败，请保留网页提示和 CMD 最后几十行，不要只截取一个英文代码。

### 内置草帽、兽耳或光环载入失败

先运行 `03_验证安装.cmd`。如果验证通过但样例仍失败，请记录样例名称、网页完整提示和 CMD 中对应时间的 `request.failed`；成功载入前出现 `TERRE_PATH_MISSING` 也应一并记录。

### 验证或安装失败

窗口底部会给出中文结论，上一行附近保留真实错误码和结构化信息。看到“没有执行产品写入”表示预检已在改动前停止；看到“已回滚”表示本轮写入已撤销；看到“需要恢复检查”时不要反复运行安装，先保留整个窗口内容。

### 管理工具自身缺文件，修复提示需要完整包

保留现有安装目录与用户资料，重新解压与当前安装版本相同的完整插件包。将原安装请求 JSON 拖到完整包的 `04_修复安装.cmd` 上运行；原请求通常位于已安装管理目录的 `config/install-request.json`，也可使用安装时保存的原请求。不要直接覆盖管理目录。工具将核对版本、安装身份和剩余文件，只恢复缺失的受管内容；已有文件被外部修改时仍会拒绝，不能把修复当作强制覆盖。完整包也无法启动或原安装记录缺失时，请保留错误日志与资料后报告问题。

### 觉得附件跟随不自然或帧率异常

先关闭所有诊断叠加和高级效果，用同一人物、同一动作比较纯人物与普通附件。记录动作名、运行约十秒的体感、是否只在附件出现时发生。锚点是否自然仍需要人眼判断，自动测试不能代替视觉确认。

## 提交问题时请带上

- 插件版本与 release revision；
- 使用的是制作器、Terre 编辑器还是真实游戏运行时；
- 从哪个编号 CMD 启动、做了哪些点击；
- 网页完整提示、CMD 对应时间段日志和截图；
- 是否发生了实际文件写入，以及能否稳定复现。

不要公开日志里的本机隐私路径或尚未授权分发的人物素材。附件制作器只在本机回环地址运行，不需要登录或联网。
