# 导入自己的人物

打开附件制作器，在第1步展开“导入自己的人物模型”。点击“选择模型文件夹”，选择包含model.json及共用动作/表情的目录；例如Anon各外观共用.mtn_exp时，选择anon文件夹，而不是单独的school_winter-2023文件夹。下拉框选定模型入口，填写显示名，再点“检查并复制到制作区”。缺失依赖时会停止且不写入。

已有Profile的模型会加入人物列表；明确选中并显示后再载入附件、调整位置。未知模型显示需要Profile，不伪造锚点；手工锚点制作仍是后续能力。

在第5步选目标游戏后，回到导入区域点击“将当前导入人物复制到第5步所选游戏”。复制成功后添加/更新到游戏；第4步保存到制作器资料库无需复制游戏模型。不会更改目标游戏原有同名人物；本次导入使用独立creator-imports路径。相同路径有不同内容时停止并保留两边文件。用户仍可编辑自己的模型文件，复制时以其现有内容重新检查依赖。

原模型仅由浏览器读取并上传到当前本机制作器服务；不移动、删除，不发送到外部服务。模型含大量动作时检查复制需要等待，结束前请勿关闭制作器。当前限制为96 MiB/2048个依赖文件。模型/Live2D SDK不随插件分发，复制已有模型不改变其原授权。

## 为什么要选整个角色文件夹，却只出现一套衣服？

文件夹是查找依赖的范围，模型入口是本次选定的外观。例如选择sakiko目录，再选school_winter-2023/model.json，只导入冬季校服及其依赖。想测试便服，可在同一目录中改选casual-2023/model.json再导入。资料库中有Profile，不代表制作区已有对应模型文件。

## 为什么同一外观有多个选项？

它们是同一模型的不同锚点配置，不是多复制了模型。普通服装列表将同一路径合并并优先使用新版语义配置；高级区仍可选其他Profile。1–3锚点的旧版/专项配置保留给已有附件。每次重新选择文件夹并执行导入都会建立独立人物副本，不会覆盖旧副本。导入完成后无需再次点击。

## 从导入到游戏的完整顺序

选择角色目录 → 选择单套外观入口 → 检查并复制到制作区 → 在上方选择角色、服装并载入立绘 → 制作/调整附件 → 第4步保存附件 → 按需在第5步选择游戏 → 回到导入区点击“将当前导入人物复制到第5步所选游戏” → 等待复制完成 → 添加 / 更新到这个游戏 → 在Terre打开添加结果给出的独立验证剧情。

制作区与目标游戏各自保留人物模型，因此“工作台能显示”和“附件可以添加到游戏”是两个检查点。复制按钮只处理当前选中的导入人物；其他模型请另行明确选择。若要创建独立作品请用“另存为新附件”；继续修改当前附件使用“保存附件”。按钮附近显示当前操作结果；出现错误时保留完整提示，不重复点击或手工覆盖目录。
