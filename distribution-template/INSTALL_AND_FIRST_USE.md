# 安装与第一次使用

Hotfix44 技术包（`WebGAL Attachment 0.5.0-beta.1`），适用于已验证 Windows x64 / MyGO 3.2.0 / WebGAL Terre 4.6.2 / `hostfix1-local` 精确宿主。先保留游戏备份；人物模型及兼容Live2D SDK须由用户合法准备，不随插件提供。

1. 关闭Terre、Creator和游戏预览，完整解压包；不要在ZIP里执行。双击`01_安装或升级.cmd`，首次会选择宿主和允许保存的游戏，核对目标目录。保留生成的安装请求文件。
2. 运行`03_验证安装.cmd`。普通窗口给出中文结果、版本和目标；详细诊断JSON在窗口所示临时目录，需要长期保留时复制到自己的记录目录。
3. 运行`02_打开附件制作器.cmd`。日志CMD保持打开。已有本地人物可直接选择；新人物按[导入指引](LOCAL_MODEL_IMPORT.md)选择整个依赖目录，再选定一套外观入口。Profile存在不代表人物资源已经导入。
4. 先选角色和服装，再点击“载入所选立绘”，再选择内置附件或PNG，调整部位、位置、缩放与角度。五套样例是普通附件；参数文件和单位见[编辑说明](EDITABLE_ATTACHMENTS.md)。
5. 在第4步点击“保存附件”，把图片、默认参数及所有立绘适配保存到制作器资料库，无需选择游戏。另存为创建新的附件身份；更多中的“导出完整附件文件夹”保留同一身份。
6. 需要在游戏使用时，在第5步选择游戏，按提示补齐人物模型，再点“添加 / 更新到这个游戏”。记录附件文件夹和独立剧情路径，在Terre打开剧情检查效果。添加到游戏不反向保存资料库，不修改原剧情。
7. 在Terre的图形编辑器中使用附件控制/舞台实体控制卡，先加载对应立绘实例，再添加附件。切换脚本和图形模式可检查参数；改稿后保存再预览。新标签页从游戏起点进入，不保证自动定位编辑器当前句。
8. 通过Terre导出Web游戏，核对导出成功和实际文件；使用普通静态HTTP服务，在关闭Terre/Creator后检查独立运行和存读档。当前不将Windows EXE或Android导出称为已验收。
9. 结束制作运行`05_停止附件服务.cmd`。`06_卸载插件.cmd`用于解除受管安装、恢复原宿主并保留用户资料，不等于删除整个目录。

修复：管理工具自身缺文件时，重新解压相同版本完整包，从包中运行`04_修复安装.cmd`并使用原安装请求。遇到冲突，保留错误与诊断；不要直接覆盖管理目录、用户模型或剧情。失败提示不是成功，诊断文件写入失败也不会改变原操作结果。

完整[已知限制](KNOWN_LIMITATIONS.md)和[排错说明](TROUBLESHOOTING.md)应与本页一起阅读。对应源码与独立构建资料见 SOURCE_CODE.md；发布者许可决定和剩余人工门禁见 RELEASE_READINESS.md。当前元数据已对齐，下一步是最终安装/GUI smoke，之后进入 `0.5.0-beta.1` 公测。





保存与添加到游戏分开：第4步“保存附件”写入制作器资料库；第5步“添加 / 更新到这个游戏”部署当前附件并生成独立剧情。五套快捷样例优先打开资料库中同身份的保存版。详见 MULTI_CHARACTER_ATTACHMENTS.md；本次变更见5L-HOTFIX37.md。
