## 来源、命名与边界

整理于2026-10-10；复用2026-10-02 Bestdori模型库、人物/服装元数据与3737入口静态审查。原六套/四备选保持身份，本轮定向复核追加纱夜022_fantasy_01与里美003_live_event_20_r。来源入口：[Bestdori日服Live2D资源索引](https://bestdori.com/tool/explorer/asset/jp/live2d/chara)，按资源标识定位。这是精选示例，不是全库唯一或最新服装清单。

服装编号为来源costumes元数据条目ID，不等于人物编号、卡片ID、图片序号或目录前缀。9套有编号，3套来源未列。名称保留来源快照文字；缺名以“（造型描述）”标明，不猜官方名。CHU²角色编号为35；资源标识区分具体外观。

图片采用原Cubism2 SDK WebGL与原生遮罩渲染，嘴部使用每套服装自己的idle01首帧参数，未统一强制微笑。12套均在本地全角色模型库找到idle动作，并核对各自默认表情；无需按角色性格猜测。友希那、燐子、纱夜的FORM_01为−0.5；爱音、真白为0；其余为1。不同模型相同数值不保证外观相同，爱音的0仍呈自然微笑。亚子的FORM_01在idle中轻微变化（0.92至1），本图取首帧1。辅助嘴部参数也按idle首帧取值。见[派生嘴部参数CSV](mouth-parameters.csv)与[JSON证据摘要](selection.json)。

本图只调整嘴部状态，不播放整段idle或物理；未修改原模型、未补画不存在的部位。是静态参考图，不代表实际宿主动作、物理、可拆网格或移植效果已验证。第三方角色/服装/图像权利归原权利人，不适用本仓库独立代码/样例PNG许可，不授予源模型再分发权。
