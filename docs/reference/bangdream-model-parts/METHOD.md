## 四种类别状态

| 状态 | 含义 |
|---|---|
| PRESENT | 明确可见外观；至少有一个具体模型代表 |
| PARTIAL | 有近似轮廓，具体结构未确证 |
| NOT_OBSERVED | 此次中性可见图及候选未找到定义内明确实例 |
| INDETERMINATE | 遮挡、分辨率、结构或定义不足，保留无法判断 |

类别有重叠和粒度差异，数量不能计算原库服饰覆盖率。存在造型、可拆用网格、工具兼容、目标移植、动态跟随与遮挡分别记录；本版只提供第一项可见形态证据。

检查图不完整实现剪裁遮罩、混合、物理、动作和表情。OurNotes面部可能有遮罩伪影；小饰品可能被头发/姿态遮住。7个剪影/登出/SOUND ONLY入口和2个特殊组合入口细节不足。15个尚未取得远端入口及隐藏状态/画面外区域不在否定范围。9个缺physics副本不能推出完整运行。

036/037/039/040_collabo_a_ur及337/338/339/340_event_297_story_01等8个入口含MASK技术命名；当前中性图裸脸。它可能是部件或其他技术用途，不能据名称确认实体面具，也不能从中立未显示判全部状态不存在。

背包背部、腿脚、内层服装等在部分正面半身图中不可见。腕表、鼻/唇环和入耳装置没有逐处近景穷举，保留未知。图中耳、翼、尾的外形也不能自动区分生物附肢与可拆服饰。

## 数据字段

模型稳定键是source:bundle；同名模型的不同来源不会自动合并。catalog.json保留人物名、外观标识、格式、粗分类、已确认或边界细类观察及限制。visibleTags是大类，detailedParts中的categoryId对应coverage.json；没记录某细类不表示它不存在。

coverage.json保留类别定义、状态、示例模型键、观察正文、相近类别与检索别名。别名只帮助检索，不添加未经核实的形态断言。

## 怎样更新

1. 为新入口或更正保留来源、模型标识、日期和可复核证据。
2. 修改JSON中的对应记录，保留不确定性；同一角色不同服装不自动共享部件结论。
3. 让HTML内嵌数据与两个JSON文件同步，重新检查记录键、类别引用、计数和搜索结果。
4. 增加本目录CHANGELOG版本项。纯资料更新不改变插件功能或插件版本。
