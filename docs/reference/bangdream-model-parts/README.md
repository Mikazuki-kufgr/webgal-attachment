# BanG Dream 原模型特殊部件索引与底模候选检索表

这份独立社区资料帮助改模创作者从“需要帽子、兽耳、耳机、头巾或口罩”找到具体人物与外观。它采用2026-10-02的已有模型检查结果，与WebGAL附件插件的版本和安装流程分别维护。你可以把这个目录整体下载或迁移到另一个资料仓库。

## 怎样查找

1. 在GitHub在线查阅本页的代表清单与说明。
2. [下载自包含检索页](https://raw.githubusercontent.com/Mikazuki-kufgr/webgal-attachment/main/docs/reference/bangdream-model-parts/index.html)（保存为index.html），双击打开。也可在[index.html文件页](index.html)选择Download raw file。GitHub文件页显示源文件，下载后才执行交互检索。
3. 搜索部件、人物或外观标识；切换“按模型找部件”和“按部件找模型”，并按来源筛选。
4. 用显示的模型标识在对应来源或你已有的素材中定位外观，再按所用改模工具核对需要的部件。

检索页不需要插件、账号、网络服务或本地服务器；页面数据全部内嵌，下载一个HTML即可使用。它只提供文字、分类和定位信息，不包含人物模型、贴图、动作或人物截图。

## 数据范围

- 3737个入口，3643个去重中性检查图组，57张总览纳入审查。来源：Bestdori3498、社区历史补档16、缺physics研究副本9、OurNotes214。
- 原盘点的大类标签覆盖所有入口；2563套被选为特殊外观，标签包含帽冠、兽耳、耳机、翼尾、主题服装等。
- 119个有定义的服饰类别：92明确出现、20本轮未发现、2近似、5无法判断。细类正例涉及162个不同入口，**只列代表，未为全部3737入口穷举细类**。类别有重叠和粒度差异，不能计算服饰覆盖率。
- 15个未取得的远端CN2019af入口不在否定范围；9个缺physics副本为静态研究资料，不能当完整运行模型推荐。
- OurNotes原包来源与v101版本权威未核实；[官方游戏介绍](https://en.bang-dream.com/news/20260302/post-70)只解释游戏背景，不是原包下载来源。未知角色保留目录名，不猜译。

“未发现”指本次已收集的中性可见图与相关候选中未发现明确形态，不能写成“官方从未做过”。背后/画面外、小饰品、隐藏参数及检查渲染伪影的观察限制见[METHOD](METHOD.md)。所有外观记录也不能替代模型使用或再分发授权。

## 为什么放在这个仓库

它服务改模与WebGAL创作者，是社区参考附录。目录在docs/reference/下，首页仅提供入口；插件代码、安装包和公测tag不依赖此资料。它不是插件功能说明，也不以出现/缺失某造型证明某种方法更优。若以后维护需求扩大，可直接将这个目录迁移到独立资料仓库，并保留来源和版本记录。

## 如何补充或纠错

在仓库[提交Issue](https://github.com/Mikazuki-kufgr/webgal-attachment/issues)，提供人物、外观标识、部件、来源和支持判断的公开链接。已有相同部件的另一套模型也欢迎补充。若要标为“已验证可拆用”，还需写清工具/版本、来源与目标外观、具体操作和验证结果。不要上传私人模型、游戏、账号或本机路径。
