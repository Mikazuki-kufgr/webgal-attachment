# 本版支持范围与已知限制

适用修订：`MYGO321-AUTO-FIGURE-SWITCH.7`。只支持 Windows x64 与指定 MyGO 3.2.1 / Terre 4.6.4 社区宿主；其他 Engine/Terre 版本、Android、跨平台和任意改装宿主尚无本版验证。

- 附件制作、保存、添加到测试游戏、Terre 内嵌预览和 B1/B2 人物切换主线已有用户操作反馈；同版手部验收场景在独立网页 H01–H09 播放、两种状态实际存读档及 Terre 图形界面网页导出也得到用户正常反馈。该网页仍有可感知卡顿，但用户确认能操作和判断效果；不把单场景结果扩大成所有游戏/模型的视觉验收。
- 自定义模型需完整依赖、相应 Profile、可用锚点及人工校准。导入模型不等于任意第三方模型自动适配；现有 Profile 元数据也不等于随包人物模型。当前手部试用能力按 Cubism 2 单 PNG 与已配置手型使用，未知或未配置手型会隐藏附件并给出诊断。
- 附件常规层位是人物整体前/后层；手部能力仅覆盖已配置的状态与局部遮挡，不承诺任意模型部件内部插层、完整 mask/clip 或所有动作物理正确。多套 adaptation 的普通编辑入口尚未完成。
- 新游戏需选择配套引擎；安装插件不会自动替换旧游戏引擎，也不会修改用户正式剧情入口。旧游戏要按界面提供的更新流程明确处理并先备份。
- Windows 网页导出应使用完整目录内的本地启动入口或 HTTP(S) 部署。直接双击 `index.html` 可能受浏览器模块限制。本地入口地址变化可能影响浏览器原有存档的访问；不要把复制目录当作存档迁移。
- “回到待机动作”快捷按钮在部分 Profile 上仍可能无效，可从动作列表选择可用动作。制作器预览性能仍受浏览器和宿主环境影响；本版没有针对未归因的卡顿采用全局帧率限制。
- 安装、升级、修复和卸载遵循写入前检查与冲突保护。遇到改装文件或占用时保留原错误并停止，不要手工删除 ownership、锁或事务记录。已安装宿主整体搬家及任意特殊路径未承诺自动恢复。

这些是诚实的使用边界，不表示上述能力在未来不会支持。遇到主流程无法使用、数据错写或明显严重问题，请附版本、具体步骤与脱敏错误反馈。
