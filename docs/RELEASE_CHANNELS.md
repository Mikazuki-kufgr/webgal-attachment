# 下载版、源码与在线说明

## 普通用户下载什么

目前推荐[MyGO 3.2.1 / Terre 4.6.4公测](https://github.com/Mikazuki-kufgr/webgal-attachment/releases/tag/v0.5.0-beta.1-mygo3.2.1)，下载该页完整命名的INSTALL.zip。它仍是公开Beta/Pre-release，不因视频发布或说明修订自动变成稳定版。SOURCE.zip为对应发行源码；GitHub自动Source code不作为安装入口，尤其不能代替迁移版命名的SOURCE。

## 三种更新分别意味着什么

| 对象 | 如何维护 | 对现有用户意味着什么 |
| --- | --- | --- |
| 已发布tag与INSTALL/SOURCE | 保留原身份和校验值，不用新内容替换同名旧包 | 已贴出的下载链接和源码仍可追溯 |
| 在线同版说明 | 标明软件tag、修订名和文档日期，修正说明/补图与导航 | 下载包未变，包内说明是当时快照 |
| 后续开发源码 | 单独说明其开发状态、依赖和支持范围，可通过开发分支或明确版本维护 | 仓库变更不自动进入已下载软件 |

主公测说明为[USER_GUIDE.md](USER_GUIDE.md)，适用`v0.5.0-beta.1-mygo3.2.1 / MYGO321-AUTO-FIGURE-SWITCH.7`。后续新版说明应另建明确入口，不能把新功能直接写成这个Beta已支持。

## 本轮调整范围

公测介绍视频已由作者发布：[观看视频](https://www.bilibili.com/video/BV1oQn56xE1T)。本次准备的文档变更更新视频入口、宿主选择、安装路径、07更新、保存恢复、命令等待、默认参数/适配/手部边界及两幅示意图；不更换软件包，不修改旧tag，不加入本地新升级源码。

## 后续升级怎样公开

先明确要公开的源码工作区和版本，核对许可/依赖、排除SDK/人物模型/用户游戏与内部协作材料，列出支持变化和验证缺口，再同步对应源码。开发状态可用独立分支维护，准备给普通用户安装时发布新版本的INSTALL/SOURCE并保留旧发行。源码同步与新安装包发布是两件事。

MyGO 3.0.0、3.1.1、3.2.0仍是按宿主并列的迁移预发布，不取代主3.2.1公测。撤下的内部视频审阅、原反馈与协作入口不因仓库恢复维护而重新公开。

“推荐下载版”由首页明确入口表示；GitHub的Pre-release/Latest标记是另一项发行元数据。当前保持Pre-release，使用上述明确tag链接，不依赖`/releases/latest`。后续若调整发行状态，应单独说明，不能让人误以为现有软件已完成稳定版验收。
